# Automated public-source research snapshots

The default-branch GitHub Actions workflow runs every Monday and can be manually dispatched. It commits dated snapshots of selected public GitHub repository metadata to `master`; no private media, case-specific Drive URLs, provider secrets, audio, or AI models are used.

The initial 2026-11-22 run successfully inspected 15 of 15 source registries. A project's most recent commit does not prove quality, codec compatibility, maintenance safety or evidentiary usefulness. Independent review and synthetic + authorized private tests are mandatory.
